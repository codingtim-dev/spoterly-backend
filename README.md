# 📸 Spoterly Backend

Backend service for the **Spoterly** web application, responsible for handling server-side logic and database interactions.

Spoterly is a university project that allows users to discover and share interesting photography locations on a dedicated platform.

---

## 🔧 Overview

The backend provides the core infrastructure required to support the Spoterly application. Its responsibilities include:

- Managing real-time connections between clients  
- Handling structured database queries and data persistence  
- Managing user sessions and application state
